## [0.1.0] - 2026-07-14

### Added
- Initial React Native calculator mobile application powered by Expo.
- Basic calculator functionalities including standard arithmetic operators, decimal precision, and memory storage.
- Project structure setup including `src/` modular routing, internationalisation (EN/VI), and state management via Zustand.
- Persistent AsyncStorage settings schema for layout preferences.
- GitHub CI configuration for linting, typechecking, and unit testing validation.
